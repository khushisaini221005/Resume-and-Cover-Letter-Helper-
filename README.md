# 📄 Resume & Cover Letter Helper

An AI-powered web application that helps job seekers generate tailored resume summaries and professional cover letters.

## 📌 Features
- 📝 **Resume Summary Generator:** Creates professional summaries tailored to job titles.
- ✉️ **Cover Letter Builder:** Drafts customized cover letters using candidate skills and job descriptions.
- 🎯 **ATS Friendly Suggestions:** Provides key suggestions to optimize resumes for Job descriptions.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Processing:** Pandas
